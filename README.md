# ספר ההדרכות – דף ההתקדמות

הדף הציבורי: https://d4040889.github.io/Siach-Ish/

איך הוא מתעדכן:
- **הגיליון "ספר ההדרכות – נתונים"** (Google Sheets) הוא מקור התכנית: תאריכים, שמות, הערות. הסקריפט שבגיליון (`tools/Code.gs` + `tools/Builder.gs`) בונה את `index.html` ודוחף אותו לכאן בכל עריכה, בכל שעה אם הסריקה השתנתה, ובכל בוקר.
- **המשימה הלילית** (Claude, בימים א׳–ה׳ ומוצ״ש) סורקת את התיקייה "הדרכות מיון" במחשב, כותבת `data/scan.json` (אילו קבצים יש, מה התקבל, אירועים) ומכינה עותקי PDF של קובצי המיון הסופי בתיקייה `files/`. הסקריפט: `tools/scan.py`.
- `data/chapters.json` – התכנית כפי שהגיליון דחף אותה (לשמות הפרקים בסריקה).
