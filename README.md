# ספר ההדרכות – דף ההתקדמות

הדף הציבורי: https://d4040889.github.io/Siach-Ish/

איך הוא מתעדכן:
- **המשימה הלילית** (Claude, בימים א׳–ה׳ ומוצ״ש ב-20:40, על המחשב) סורקת את התיקייה "הדרכות מיון", כותבת `data/scan.json` (אילו קבצים יש, מה התקבל, אירועים), מכינה עותקי PDF של קובצי המיון הסופי בתיקייה `files/`, ובונה מחדש את `index.html`. הסקריפטים: `tools/scan.py`, `tools/build_page.js` + `tools/Builder.gs`.

- `data/chapters.json` – התכנית מהגיליון (כולל תאריכים ידניים). `data/site.json` – כותרת, יעד סיום, הודעת הסוף וקבצים מתיקיית ה-Drive.
- שני הבונים משתמשים באותו מנוע (`Builder.gs`) ובאותם נתונים, ולכן מפיקים אותו דף בדיוק.
